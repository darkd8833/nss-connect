# NSS Connect Meeting Templates

## Project kickoff

### Purpose
Align the team on the pilot outcome, users, scope, and decisions needed.

### Agenda

1. User problem and desired outcome
2. Current prototype walkthrough
3. Pilot users and workflow owners
4. In-scope and out-of-scope features
5. Data, privacy, and access expectations
6. Milestones and owners
7. Risks and open decisions

### Outputs

- One-sentence product goal
- Pilot group and target date
- Decision owners
- First milestone acceptance criteria
- Updated risk register

## Weekly delivery review

### Metrics

- Features completed
- P0 items remaining
- Critical defects
- Smoke-test status
- Deployment status
- Open decisions older than one week

### Questions

- What user outcome improved this week?
- What is blocked?
- Did any risk increase?
- What should be stopped, started, or continued?
- What will be demonstrated next week?

## Pilot feedback session

### Ask users

1. What task were you trying to complete?
2. Where did you hesitate or need help?
3. What information was missing?
4. What did you expect to happen?
5. What would make this workflow faster?
6. Was any information difficult to trust or verify?

### Capture each issue

- User role
- Workflow
- Expected behavior
- Actual behavior
- Severity
- Screenshot or reproduction steps
- Suggested improvement
- Owner and target release
